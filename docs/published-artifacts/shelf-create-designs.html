Five ways to start a note or a session from the shelf

Every frame is drawn at the app's real scale, with the rail fixed at 14px and the card at 340px. The new-session card is a small session in each design, not the full composer. The page follows your light or dark setting so you can judge both themes.

00

Today

The plus and pencil are 10px glyphs in 22px rows at the bottom corner, so they are easy to miss. The note card opens on a project picker and two bare inputs, and has no heading. The plus leaves the shelf and opens the full composer, with board, ticket, model, mode tabs, tools, folder, provider, approval and code intelligence.

01

Bookmark ribbons

The two actions hang off the shelf as ribbon bookmarks, coloured by what they make: terracotta for a session, amber for a note. The open one grows longer and fills solid. Both cards copy the session preview card line for line, so a new session looks like a session that hasn't started yet.

  • One card language. New session, session preview and note share meta row, title, body, reply and footer.
  • Project in the header. The picker becomes a chip, so the note opens on its title, not on a drop-down.
  • Clear colour coding. Accent means session, amber means note, on the rail and on the card edge.
  • Risk: ribbons take 72px of rail height, 28px more than today.
02

Chat stub and sticky note

Two small tinted tiles sit on a soft fade at the foot of the rail. The session card opens as a chat that the agent has already started, with quick starters and a two-line composer. The note is a sticky note: a warm paper colour with no form boxes.

  • Feels like a session. The agent opens the conversation, so the card reads as chat before anything is sent.
  • Agent and mode up front. Agent, project and Ask/Edit are the only settings; everything else uses defaults.
  • Note to session in one press. "Discuss with Claude" seeds a new chat with the note.
  • Risk: a pre-written agent line is not a real model message, so it should be styled as a prompt and not stored.
03

Empty slots

The actions read as gaps on the shelf where a new book will go: a dashed spine for a session and a short pen stub for a note. The session card is a blank book with a dashed edge that turns solid once you start typing. One sentence holds every setting, and you click a word to change it.

  • Truest to the shelf idea. The buttons look like part of the bookshelf, not toolbar icons added to it.
  • Settings as a sentence. Agent, permission, project and approval in one line you can read aloud.
  • Visible draft state. Dashed while empty, solid once it has a goal.
  • Risk: dashed lines look faint on low-contrast palettes such as solarized-light.
04

One capsule, one card

Both actions share one bordered capsule, so they read as a single "create" control. Either one opens the same card with Session and Note tabs, and Tab switches between them. A note can be attached to a new session from inside the card.

  • Smallest rail change. 40px tall, about the 44px used today.
  • Writing and asking stay together. A note becomes a session goal without retyping.
  • Tab to switch. Session and note are one keystroke apart.
  • Risk: two meanings in one capsule; each half still needs its own aria-label and tooltip.
05

Labelled spines

Real book spines carry their titles sideways, so these do too. Each action is a 64px spine with a glyph and a vertical label, SESSION or NOTE, at 7.5px. The cards open with a coloured header band, and the session is a two-line transcript that you continue.

  • No guessing. The only design where the button says what it does without a tooltip.
  • Transcript as composer. Context sits on one system line; your goal is the first line of the session.
  • Continue instead of new. The footer offers today's sessions in case you meant to add to one.
  • Risk: 128px of rail height, and 7.5px text is at the edge of legibility on Compact scale.
Recommendation

Use 01's cards with 02's tiles

  1. Cards from 01. A new session drawn as an unstarted session preview gives the shelf one card shape for preview, new and note. It also cuts the composer to project, title, starters, agent line and reply.
  2. Rail from 02. Tinted 12px tiles are the clearest gain over today's bare glyphs and keep the rail height close to the current 44px. Take 05's labels instead if discoverability matters more than height.
  3. Note to session from 04. "Use as session goal" on the note card is cheap to add and joins the two flows.
