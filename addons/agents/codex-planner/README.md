# Codex Planner

Runs the built-in **Praxis Planner** on **Codex** (`codex-acp`), whatever
runtime the session uses. The agent's instructions stay the built-in's — this
add-on only chooses the runtime.

- One add-on runs a built-in agent at a time: installing another one for
  Praxis Planner uninstalls this one.
- Uninstall it and Praxis Planner goes back to the session's runtime.
- Needs Codex set up in Praxis (Settings › AI Provider).
