# Claude Reviewer

Runs the built-in **Praxis Reviewer** on **Claude Code** (`claude-agent-acp`), whatever
runtime the session uses. The agent's instructions stay the built-in's — this
add-on only chooses the runtime.

- One add-on runs a built-in agent at a time: installing another one for
  Praxis Reviewer uninstalls this one.
- Uninstall it and Praxis Reviewer goes back to the session's runtime.
- Needs Claude Code set up in Praxis (Settings › AI Provider).
