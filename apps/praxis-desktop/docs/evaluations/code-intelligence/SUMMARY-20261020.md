# Code intelligence semantic search — summary of experiments (19–20 Oct 2026)

Agents now get the best measured search by default. Plain-language questions about
TypeScript/JavaScript go to semantic search; names, short phrases and C# go to hybrid. On the
evaluated sets this finds as many or more answers than the old hybrid-only default, at about
0.3 s per question search (Release, warm) instead of about 0.1 s.

All relevance labels are AI-authored and have not been independently reviewed. All results are
retrieval metrics (is the expected symbol in the top 10, and how high), not agent answer quality.
