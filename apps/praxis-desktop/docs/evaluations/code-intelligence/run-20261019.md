# Retrieval baseline after five self-reviews

19 October 2026. All five [self-review passes](self-review.md) completed before collection. No corpus questions, relevance labels, split, model or ranking weights changed for this run. This is an actual production-engine measurement, not a simulated answer or a replay of the earlier workflow pilot.

## Headline: held-out natural-language queries

64 terminology/behaviour queries, representing **32 behaviour families across eight held-out domains**. Exact-name controls and false-premise questions are excluded from this headline.

| Mode | Primary answer in top 10 | Hit@10 | Hit@1 | MRR@10 |
| --- | ---: | ---: | ---: | ---: |
| Lexical | 33/64 | 51.6% | 23.4% | 0.310 |
| Semantic-only | 40/64 | 62.5% | 26.6% | 0.373 |
| Hybrid | 39/64 | 60.9% | 32.8% | 0.428 |

Semantic-only finds seven more primary answers than lexical. Hybrid finds six more and puts the first primary answer higher overall. MRR assigns 1 to rank 1, 0.5 to rank 2, and 0 to a miss, so larger is better. Neither mode retrieves every required implementation: semantic-only misses 24/64 and hybrid misses 25/64 under the frozen primary-anchor labels.

Predeclared paired percentile bootstrap, 10,000 resamples of **families**, seed 20261019:

| Difference against lexical | Estimate | 95% interval |
| --- | ---: | ---: |
| Semantic Hit@10 | +10.9 percentage points | -1.6 to +23.4 points |
| Hybrid Hit@10 | +9.4 percentage points | +1.6 to +18.8 points |
| Semantic MRR@10 | +0.064 | -0.038 to +0.167 |
| Hybrid MRR@10 | +0.118 | +0.055 to +0.191 |

Hybrid's intervals exclude zero in this labelled sample; semantic-only's do not. These are exploratory bootstrap intervals, not independent human validation or a universal improvement guarantee. A post-run sensitivity check clustering by the eight domains, to allow for related functions within components, gives Hit@10 intervals of -1.6 to +23.4 points for semantic and +4.7 to +15.6 for hybrid. Eight domains are too few for a strong generalization claim; retain the predeclared family analysis as the primary one.

## What this establishes

This broader baseline supports an advantage for hybrid **primary-answer retrieval and ordering** over lexical search on this sample. Semantic-only finds the most targets, with wider uncertainty and domain regressions. The results do not demonstrate accurate retrieval for every question or improved agent explanations.

The labels remain AI-authored seed judgments. Other useful implementations or tests may be unjudged; complete pooled relevance review and nDCG are not claimed. The index's intentional syntax-only fallback context is still present and global freshness remains partial, so this is not the stricter repository release-acceptance protocol. Agent comparisons and the six controlled lifecycle scenarios remain unexecuted. Any tuning informed by these results must use fresh acceptance data; this baseline is now observed.
