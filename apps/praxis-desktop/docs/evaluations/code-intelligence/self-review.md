# Five self-review passes before measurement

19 October 2026. Reviewer: the authoring Codex agent. These are five deliberate reviews of different failure modes, **not five independent reviewers or human approval**. No held-out search rankings were used to perform them, and the corpus text, labels and split were not changed.

1. **Source and question validity.** Rechecked local dataset validation, the 48 exact implementation selectors and the recorded source evidence. All 24 labelled source files match their saved hashes. The fixture preparation also checked all 597 indexed source files against the index's observed hashes with zero mismatches. Primary labels remain implementation anchors; they do not exhaust all useful results. The run must be described as anchor retrieval, not complete relevance or agent answer quality.

2. **Leakage and independence.** Rechecked normalized query uniqueness, family isolation, source-file isolation, supporting labels and agent-task assignment. Development-only domains do not establish held-out quality for those domains.

Supporting grade-1 labels are not promoted to primary answers. Pooled nDCG remains unmeasured without pooled judgments.
