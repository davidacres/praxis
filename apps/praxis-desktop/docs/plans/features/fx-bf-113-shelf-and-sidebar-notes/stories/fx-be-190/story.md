# FX-BE-190: Capture notes from the fixed shelf and sidebar

## Goal

Provide one notes collection and editor through both navigation surfaces.

## Acceptance criteria

- Fit plus and etched pencil actions inside the current 14px rail. Reuse session creation. Open the notes editor in an edge-attached sleeve, retain current session hover/reply behaviour and keyboard access, and prevent loss on dismissal. Verify empty/full rails, overflow, focus and Escape without horizontal expansion.
- Add the same Notes section in Classic and Easy Mode with compact themed rows, expandable named groups, creation, rename, membership, removal and deletion actions. Use menu actions for grouping so drag is optional. Share selection/editor state with shelf access. Autosave with visible errors and retry; preserve text across navigation, project switching and restart.
